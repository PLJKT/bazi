# 己土堂 · 个人命理决策支持系统（bazi）

自包含单文件双语命理决策系统，围绕用户本人（己土日主）构建家庭、事业、人脉、战略与流年的一体化决策支持工具。

**在线访问**：<https://pljkt.github.io/bazi/>（GitHub Pages · 公开部署）

**登录口令**：`admin / admin@123`（前端登录锁，代码可见；正式公网使用建议后续改为私有部署或更换口令）

## 技术架构

- **单文件自包含**：`index.html`（约 195 KB，UTF-8 无 BOM），Tailwind CDN + 内联 CSS/JS，无外部构建
- **双语机制**：`I18N.zh / I18N.en` 字典（各 534 键）+ `t()` + `applyLang()`；`localStorage.bazi_lang` 默认 `zh`；全部内容随语言切换，中英严格一一对应
- **状态持久化**：语言选择 `bazi_lang`、登录状态 `jitang_unlocked`、合盘自定义人物 `bazi_custom_people`
- **锁定口径**：所有人物四柱与页面显示以「校准记录」为准，修改需同步 zh/en 两侧 + HTML 默认文本

- 仓库当前为**公开**，含家人八字、健康（2018 肺疾）与事业人脉分析等敏感信息；如需保密请转回私有仓库并升级 GitHub Pro 启用私有 Pages，或改用第三方托管
- 头部标注「本地加密使用」，建议敏感数据以本地运行版本为准

## 开发与部署流程

1. 本地主副本：`index.html`（本机开发目录）
2. 同步：`Copy-Item ..\index.html .\index.html -Force`
3. 提交：`git add index.html` + `git commit`（署名 PLJKT）
4. 推送：`git push origin main`
5. GitHub Pages 自动构建发布：<https://pljkt.github.io/bazi/>

**改动规范**：中英字典键数必须一致（zh/en 各 534）；新增键须同时写入两侧；HTML 默认文本与字典内容必须同步；每次改动后跑验证脚本。

## 验证工具（本地 `_shots/`）

- `verify_linux.py` / `verify_v2.py`：字典键对齐 + 内联 JS 语法检查（`node --check`），输出 PASS 为准
- `chk_keys.py`：字典键快速检查
- `backcalc.js`：四柱反推公历日期（8 人唯一命中）
- html skill `shot.py`：页面自检（桌面 + 移动截图，0 error / 2 条 Tailwind 历史警告）
